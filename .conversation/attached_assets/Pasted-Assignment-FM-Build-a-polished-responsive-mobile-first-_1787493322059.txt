Assignment FM 🎧

Build a polished, responsive, mobile-first music web app called “Assignment FM” for engineering college students.

Core Idea

Assignment FM is a fun, aesthetic music discovery website where engineering students can play background music while doing assignments, studying, coding, or surviving deadlines.

The website should feel like a real curated music platform, NOT like a generic dashboard.

Tagline:

“Press Play. Start Writing. Survive Engineering.”

Use a youthful engineering-college aesthetic with subtle humor, beautiful typography, smooth animations, rounded cards, and a premium modern feel.

FEATURED SONGS

Create a horizontal/vertical song-card section.

Each card contains:

- YouTube thumbnail
- song title
- artist/channel
- category
- duration if available
- Play button
- Add to playlist button

Example songs can initially use royalty-free / creator-permitted music and official YouTube embeds.

Player should contain:

- thumbnail
- song title
- artist
- play/pause
- previous
- next
- progress bar
- volume
- playlist queue
- minimize/maximize button

Use YouTube iframe/embed playback where appropriate.

DESIGN

Visual direction:

- Dark premium music-app aesthetic
- Black / charcoal base
- Soft gradients
- White typography
- One vibrant accent color
- Glassmorphism used lightly
- Large rounded cards
- Beautiful album artwork
- Smooth hover animations
- Subtle shadows
- Modern sans-serif typography

Do NOT make it look like Spotify's exact UI.

It should have its own identity.

Use a warm student/college vibe rather than corporate SaaS styling.

TECHNICAL REQUIREMENTS

Use:

- React
- Vite
- Tailwind CSS
- shadcn/ui where useful
- Lucide icons
- Responsive design
- Component-based architecture

Create reusable components:

- Navbar
- Hero
- MoodCard
- PlaylistCard
- SongCard
- SongLibrary
- MusicPlayer
- SearchBar
- CategoryFilter
- Footer

Keep song/playlist information in structured JavaScript data so songs can easily be added later.

Avoid unnecessary backend/database complexity for the first MVP.

The first version should be a beautiful, fast, fully functional frontend.

Focus heavily on:
UI polish + music interaction + mobile experience + shareability.

Make animations subtle, smooth and premium.
